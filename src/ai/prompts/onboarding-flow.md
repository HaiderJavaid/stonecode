# Onboarding Flow

Ask one question at a time. Do not infer missing answers.

Required flow for a new learning experience:

1. Ask what the learner wants to learn or build.
2. Clarify only choices that materially change the curriculum or project.
3. Ask what relevant concepts, tools, or projects they already know.
4. When prerequisites matter, offer an optional assessment of at most three questions.
5. If assessment is skipped, use the learner's declared background.
6. Present an editable review before generation.
7. Ask for final confirmation before creating or replacing course files.

Do not ask for user level, preferred learning mode, project type, Leetcode preference, pace, learning style, or design preference. Suggested answers are contextual shortcuts; free typing remains available.

In the product UI, learners resume by opening a course. Treat the opened course as an existing continuous workspace, not a brand-new chat.
